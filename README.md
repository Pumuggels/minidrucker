# minidrucker

Unofficial web app (PWA) for printing from Android to the cat thermal
printer PD01 (BLE name "PD01") without the manufacturer app.
It runs entirely in the browser (Chrome on Android, Web Bluetooth);
images are processed locally and not uploaded.

Use at your own risk. Not affiliated with the printer manufacturer.

The printing protocol follows rbaron/catprinter, see NOTICE.md.
